## Design Guidelines

- Background color: #1a1a2e (your theme color)
- Logo: Centered, approximately 30% of screen width
- Keep design simple - splash screens show briefly during app launch

## Quick Generation Tool

Use https://progressier.com/pwa-icons-and-ios-splash-screen-generator or similar tool to generate all sizes from a single high-resolution image.
